# 头颅树（介绍片收尾机制）

Status: ready-for-agent

规格：[spec.md](./spec.md)。

## Notes

介绍片 [`video/intro/脚本.md`](../../video/intro/脚本.md) 需要一个“量变引起质变”的收尾，而不是让某一颗头当高潮。方向是“摆放”：MC 的头本来就是拿来摆的，摆放之后解锁新东西。2026-10-08 暂定采用前段挂头伏笔、口播结束后接鬼屋 / 闹鬼 MV 的结构；具体玩法仍待定。本文件只记讨论到的决定和未决问题，还不是规格；定完再写 `spec.md` 和 `issues/`。

现状事实（2026-10-08 查代码）：

- 17 种新注册的头目前只有物品形态，没有方块形态；僵尸头、苦力怕头是原版物品，原版本身可放置。
- 手持头右键目前是“装备到头盔槽”，摆放需要另定操作。
- [HANDOFF.md](../../HANDOFF.md) 已拍板“无头身体不能把头安回去”。

## Decisions so far

- 结尾不用铁傀儡头当高潮：单颗头当高潮，全片就成了给它铺路。兔子头 80 格加高空连扔铁傀儡头的组合也否决了，观感和趣味都没有质变。
- 收尾必须是新机制，体现量变引起质变。
- 摆放算头部的一种能力。早先的转折台词方向（用户原话）：“我们给头做了这么多功能，但是 MC 头本身就是用来摆放的，行，那摆放之后，就会解锁……”；本轮暂定把高潮交给口播结束后的 MV，收尾正式台词待定。
- **必须有头颅树**。灵感：暗黑 / 血腥题材电影、游戏里挂满人头的树。
- 否决：把头竖着叠成图腾柱（太草率）。
- 否决：无头骑士（树里骑出 Boss 扔头），用户认为没必要。
- 想蹭万圣节（10 月 31 日）的热度，具体怎么结合待定。

### 暂定：挂头伏笔 → 诡异升级 → 闹鬼 MV（2026-10-08）

- 用户认可“前面轻轻露出那棵树，让挂头成为日常动作”，暂定采用。前段通过零星的挂头短镜头埋伏笔，呈现同一棵树逐渐挂满；具体插入段落和镜头数量未定。
- 前面的主体仍是头部功能介绍。结尾先结束口播，再以画面和音乐完成高潮；MV 中不继续解释功能，MV 后不再接一段口播结束语。
- 挂头的积累伴随树越来越诡异。诡异变化的具体表现待定。
- **最后一颗头挂上时，BGM 突然响起，进入鬼屋 / 周围物件群魔乱舞的闹鬼 MV。** “最后一颗”是目前的视频触发设计，尚未决定游戏内按种类还是数量判定挂满。
- 鬼屋 / 闹鬼 MV 是当前暂定的收尾方向；物件如何获得头的能力、哪些物件会活动、具体动作和游戏规则仍未拍板。
- 原话中的“我们的头挂的越来越慢”暂按“头越挂越满”理解。尚未将“挂头动作逐渐变慢”定为节奏要求。

用户原话：
> 这个可以，暂定用这个吧，记录下来吧，前面先埋个伏笔，结尾可以直接结束口播，然后来一段mv。当我们的头挂的越来越慢的时候，树越来越诡异，挂了最后一个头的时候，突然开始响起bgm，开始来一段闹鬼的mv

### 已定：闹鬼 = 头附身物件（2026-10-08 第二轮）

- **头看得见地附身**：闹鬼开始时，头从树上飞出，落到物件上，那件物件随之活动并使用该头的能力。因果靠画面交代，不靠口播。
- **性质是演出，但伤害照旧**：不做成需要玩家通关的挑战，也不让玩家指挥；物件使用能力时该有的伤害、破坏照常发生。
- **一种头附身多件物件**：不能“几颗头就几件物件”，否则场面不够；同一种头要附身多件同类物件。
- **专门的闹鬼小镇场景**：主要用来拍最后的 MV。由 agent 直接生成小镇；每次群魔乱舞后可以用命令恢复或重建。
- **配对表全部要做**（9 组）：

| 头 | 附身物件 | 行为 |
| --- | --- | --- |
| 青蛙 | 箱子 | 箱盖张开，吐舌头把东西或人拉进来（宝箱怪） |
| 僵尸 | 雕刻南瓜 | 一蹦一蹦追人咬 |
| 羊驼 | 发射器 | 连发吐口水 |
| 闪电苦力怕 | 避雷针 | **在周围随机劈雷**（不是瞄准某人） |
| 烈焰人 | 熔炉 | 壁炉失火溢火，仅视觉（2026-10-11 调整） |
| 山羊 | 矿车 | **范围内乱跑乱撞，能破坏方块；路过能上车的生物就捎上** |
| 兔子 | 盔甲架 | 一下比一下高地连跳 |
| 鸡 | 地毯 | **只随机附身几块地毯飘起来**，不要把所有地毯一下掀起来 |
| 蝙蝠 | 灯笼 | 仅灯忽明忽暗，不摇晃、不触发声呐（2026-10-11 调整） |

- 被动类的头（猪、牛、羊、狐狸、犰狳、狼、铁傀儡、末影人、苦力怕、蜜蜂等不在表内的）**不附身**，闹鬼时各分一颗幽灵头在范围内穿墙游走（2026-10-11）。

### 已定：附身数量、时段与触发范围（2026-10-08 第三轮）

- **幽灵头分身**：每种头从树上飞出，在小镇上空分出几个半透明发光的幽灵头，各自扎进一件对应物件；树上的真头留在原处发光。每种附身数量可用命令调。默认：南瓜 6～8、灯笼 6～8、地毯 4～5（随机挑）、箱子 / 发射器 / 盔甲架各 3～4、避雷针 / 熔炉 / 矿车各 3。用户：“可以先这么弄”。
- **时段**：默认**半夜开始，持续到黎明**。另有一个命令，直接把时间变成夜晚并立即开始，供拍摄用。
- **触发范围**：普通生存世界也能触发。条件是头颅树挂满，且范围内能找到对应的附身物件；找不到某类物件，那一类就不附身。
- 结束时的表现沿用助手提案，用户未反对也未明确确认：物件定住，幽灵头飞回树上，物件在停下的位置变回方块；拍摄场景用重建命令恢复。

用户原话：
> 默认是半夜开始，持续到黎明，也可以一个命令直接变为夜晚然后开始
> 都可以触发，只要是挂满头，然后范围内能找打对应附身物的，就可以

### 已定：专用枯树与挂头规则（2026-10-08 第四轮）

- **头颅树是单独做的闹鬼枯树模型**，不是在任意原版树上挂头。外观参考用户给的图：没有叶子、枝杈扭曲伸展的枯树（参考图：`~/.cursor/projects/Users-nakami-Documents-code-mc-mods-mc-head-function/assets/image-0a2f9ed6-cac0-41fb-8bb7-0d2bb250a993.png`）。
- **挂头方式要简单**：手持头右键点枯树，头直接瞬移到一个空的可挂点上。因为是专用树，不再需要判定“同一棵树”。
- **取下**：潜行加空手右键挂着的头；闹鬼期间不能取。
- **挂满 = 19 种头全部挂上**。没有配对物件的头不附身，留在树上发光当气氛。
- **挂满后每晚都闹**，玩家想停就摘一颗下来。
- **附身范围**：以树为中心 48 格。
- **越挂越诡异**：按已挂种类数分档变化，具体表现待定（候选：眼睛夜里发亮、起雾、落叶、树皮变暗）。
- 雷击点火照原版保留、结束表现按提案，这两条用户未反对。

用户原话：
> 简单挂就行了，我建议单独做一个闹鬼的枯树模型出来，右键点击瞬移到可挂点就行了
> 比如图上这样的枯树
> 潜行加空手右键挂着的头。闹鬼期间不能取。
> 其余按照推荐

实现约束（2026-10-08 查代码）：现有头技入口都是 `ServerPlayerEntity`，并和玩家状态、熟练度、背包、视角同步绑在一起；`FrogTongueEntity` 的主人也必须是正戴着青蛙头的玩家。物件不能直接调用头技，需要把各效果的核心抽成与来源无关的部分，或为物件单独实现。

用户原话：
> 演出，但是伤害不变，该有的还是有，然后预计得专门做一个闹鬼的小镇的场景出来（你可以直接生成这个小镇出来），每次群魔乱舞后，可以通过命令恢复，或者重建。这个主要是用来拍最后的MV准备的
> 你列出来的配对全部都要做
> 以上闹鬼的时候，不要有几个头就有物品被附身，不然效果不够好，最好一个类型的头多附身几个

### 已定：闹鬼时南瓜躁动（2026-10-11）

- 范围内没被选中的雕刻南瓜和南瓜灯原地躁动：抬起歪头、悬停后骤然回正、冷色眼火、齐灭眼、底部烟气。未雕刻南瓜和戴南瓜的盔甲架不参加。
- 没挂僵尸头也躁动。用户实机反馈后调整：正在蹦的宿主南瓜撤掉躁动眼火和原地动作，只保留附身追咬。
- 开场先齐点眼约 3 秒，再被幽灵头扎走。不改方块朝向，不占配对表。
- 规格见 [spec.md](./spec.md)「躁动」；任务见 [issues/11-restless-pumpkins.md](./issues/11-restless-pumpkins.md)。

### 已定：先实现首版再讨论（2026-10-08）

- 用户：“把已对齐方案全部落了，另外其他有啥不确定的，我建议你先实现一版出来，我们再讨论。”
- 已对齐方案和首版默认写进 [spec.md](./spec.md)，首版默认统一标〔首版默认〕；任务拆在 [issues/](./issues/)，索引在 spec 文末。

### 已定：青蛙箱子先清路再拉（2026-10-11）

- 出舌先对挡路方块一口一口抓：黏住、拉回箱子，再伸出去咬下一块；不吃基岩、枯树、宿主和带方块实体的方块。路径清空后再拉生物。
- 用户原话：中间有遮挡会导致舌头一直卡住，建议先把路径上的方块一个个吃掉，再把生物拽过来。看过视频后补充：第一口黏住第一个阻挡物拉回箱子，再第二口咬第二个，反复这个操作，而不是一次性做完。

## Fog

下面的未决项在首版里已按 spec 的〔首版默认〕先实现，留待看了首版效果再讨论。

- **闹鬼剩余细节**（附身方式、配对表、性质、分身数量、时段、生存可触发已定，见上）：半夜到黎明之间挂满是否立即开始；伤害波及谁（是否排除挂头的人）。
- **小镇与命令**：小镇规模和风格；恢复用“按代码重建”还是“存快照再还原”，或两者都要；拍摄命令（开始 / 停止闹鬼、重建小镇）是只给开发环境用，还是随模组发布、要求 OP 权限。
- **此前的其他候选**（保留讨论历史，未作为本轮收尾方案采纳）：
  - 万圣变装夜：午夜树上的头飞出去，套到周围生物头上，生物用所戴头的能力，天亮结束。卖点是视角翻转（前面头给玩家能力，这里给生物），呼应万圣节变装。用户回复“待定”。
  - 头颅树结果：挂满后树长出新头，可结出万圣南瓜头当第 20 种头。逻辑顺，视觉弱。
  - 头颅树活过来：拔根走路，枝上每颗头各放技能。观感强，但本质是之前的巨像换了树的外形。
- **枯树本身**：生存里怎么获得；模型尺寸和占地；可挂点有几个；同一种头能否重复挂（若可挂点正好 19 个且每种限挂一颗，挂满就等于 19 种齐）。
- **量变阶段的具体表现**：已暂定“越挂越诡异”；雾、落叶、眼睛夜里发亮等仍是候选。曾提议无头身体夜里聚到树下，未采纳；它与“无头身体不能安回头”是否冲突，取决于解锁内容。
- **血腥程度**：曾建议走暗黑童话、不见血，兼顾 MC 画风与平台审核。用户未确认。
- **万圣节怎么结合**：视频已暂定用闹鬼 MV 营造氛围；游戏内是全年可用加万圣节额外演出，还是只在万圣节可用，还是只在视频包装上蹭，仍待定。
- **工期**：是否赶 10 月 31 日前发片；赶的话要砍到最小可拍版本。
- **视频衔接细节**：前段挂头伏笔、口播结束后由最后一颗头触发 BGM 和闹鬼 MV 已暂定；伏笔插入位置、口播最后一句、MV 音乐 / 时长 / 镜头编排、冷开场是否预告头颅树仍待定。兔子头段原来的结尾台词“以前是我把头挂墙上……”已删掉。
