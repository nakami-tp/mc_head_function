# 11 躁动南瓜

Status: ready-for-human
Blocked by: 05, 07
进度：按首版实机反馈调整（2026-10-11），待复看新观感。

## 内容

闹鬼时给附身范围内仍留在格子上的雕刻南瓜和南瓜灯做原地演出，宿主南瓜不再叠加躁动效果。

- 纯规则放进 `HauntRules`：是否在闹鬼、附身范围、齐点眼 60 tick、齐眨眼时钟、眼火强度、南瓜灯弱一档、距离衰减、叹气预算。
- 客户端气氛模块扫描镜头附近的躁动方块，绘制慢抬、歪头、悬停、骤然回正的本体动作，眼窝冷色尖焰随姿态移动，底部升起烟气。不改 `FACING`，不改方块亮度。
- 宿主南瓜仅保留自身附身追咬渲染，不参加本模块。
- 没挂僵尸头也躁动。开场看见闹鬼从关到开才齐点眼；重进不补播。
- 未雕刻南瓜、盔甲架脑袋不参加。

## 验收

- JUnit：闹鬼外眼火为 0；齐点眼 60 tick 内不眨眼且更亮；之后共用时钟闭眼；南瓜灯弱于雕刻；16 格内满、40 格外熄；范围外为 0。
- `./gradlew test --tests com.nakami.mcheadfunction.rule.HauntRulesTest` 通过。
- `./gradlew runPumpkinValidation`：固定镜头拍安静、齐点眼、躁动中、最少粒子、结束、宿主；未雕刻南瓜不点眼。
- `python3 scripts/testing/check-pumpkin-effects.py build/pumpkin-validation/screenshots`：检查冷色鬼火在开场及最少粒子下可见，24 帧轮廓采样证明本体移动，结束后眼火消失。
