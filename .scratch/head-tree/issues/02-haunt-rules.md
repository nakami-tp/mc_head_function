## 内容

在规则层新增闹鬼规则（不依赖 Minecraft 运行时），供后续方块、生命周期和命令共用：

- 闹鬼时段：一天中 18000（含）到 23000（不含）。
- 夜晚编号：同一晚内的时间得到同一个编号，跨天递增。
- 是否开始：至少 8 种、不在闹鬼、世界未关闭、在时段内、这一晚还没闹过。19 种挂齐时立刻开始，白天也会开场。
- 是否结束：到了这次开场对应的黎明（白天开场会撑到当天黎明）。
- 诡异档位：已挂数量 0–3 / 4–5 / 6–9 / 10+ 对应 0～3 档；10 颗起任何时候头发光。
- 挂满：19 种头都在。关闭闹鬼后不再自动开场。
- 挂头结果：允许 / 已挂同种 / 闹鬼中；取头结果：允许 / 闹鬼中 / 没有可取的头。
- 下一个空挂点：19 个挂点中第一个空位，没有则表示满。
- 配对表：9 种头对应的附身物件类和默认件数；查不到的头不附身。
- 件数上下限：0～64。
- 随机挑选：从候选中挑最多 N 个、互不重复。
