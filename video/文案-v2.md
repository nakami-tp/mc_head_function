# 开场

（盔甲架，八颗头一字排开，都只是静静地摆着）
MC里的头，光拿来摆着，多少有点浪费。
所以我做了个模组，添了几颗新头，并加了亿点功能。

# 僵尸头：获取与基本用法
先从僵尸开始
拿到僵尸头，左键往外一扔
它就会自己蹦着找目标咬。
身子虽然丢了，但胃口没丢。

戴到头上，又是另一套技能。
以前回血靠干饭，现在口味倒着转：
吃别的都是毒，吃腐肉才是补
不仅回血还送力量和急迫效果

而且近战打人还能吸血，
别人打架掉血，我打架回血。
血量越低，伤害越高
攻速和移速都会更快。
别人残血想着跑，我残血还想追着咬。

那么代价呢，代价就是饱食度永远填不满，血还一直往下掉。
这下我见谁都想上去砍一刀
不是我攻击性太强，我只是饿了

# 末影人头
僵尸头让我打架有帮手，
那么末影人头让我干活不用动手。

往地上一扔，就会连着啃相邻的同种方块。
一次最多十六块，啃完还有掉落物。
头负责干活，我负责捡。
多收集几个头，一起扔出去，挖矿、砍树，多线程并行，非常的省心。

戴上以后，挨打瞬间会触发瞬移闪避。
可以躲掉一次伤害，每次只要两秒冷却，保命能力直接起飞。

不过，落点好像是随机的。
(展示卡在墙里)
运气不好，会变成这样。
攻击是躲过去了，接下来该喊人救我出去了。

（第一次挂头）
玩完的头如果暂时不用，可以放到盔甲架上，也可以统一挂到这棵树上。
收集党的老毛病了。

# 头获取方式
不过，头虽好用，获取起来实在不方便，还得请闪电苦力怕去炸。
所以为了稳定的获取头，
装备上这个拳套，对着生物哐哐三拳直接把头打掉
（展示打末影人、僵尸、苦力怕画面）
苦力怕直呼摸不着头脑，没了头也不会爆炸了

# 苦力怕头
那它的头又能干什么？当然是直接当手雷使。
扔出去3s后爆炸
也能拿在手上温一温，捏个瞬爆。
(引燃的时候闪白 + 音效)

周围生物听到这动静会叠加恐惧值
1级落荒而逃
2级发抖减速
3级还有意外收获
鸡下蛋，羊掉毛，村民连忙交出手里的钱。
不动手，直接把保护费都收齐了。

那苦力怕，你能给我交点什么？
(点燃引线，追着苦力怕跑)
以前都是我害怕，今天换你体验一把。
我这心理阴影有多大，你现在知道了吧？

跑啊，你怎么不跑了？
……不是，你怎么开始亮了？
我是让你爆点装备，咋还和我拼命呢？


戴上就更有意思了。
按 R 放一发弹药，再按 R 遥控引爆。
可以当遥控炸弹使用
另外这次爆炸对本人不造成伤害，还可以作为强力赶路工具把自己炸飞
(插入瑞兹的一些语言或者梗)

# 闪电苦力怕头

换成闪电苦力怕头，扔出去还能穿墙开路，大约八格后爆开。
戴上后，对准十六格内、没被方块挡住的怪，按 R 就能劈雷。
平时五秒充好，雷雨天只要两秒半。
天气越差，我发挥越好。

（一秒插入：第五颗挂上）

# 山羊头
接着试试这颗山羊头。
扔出去，能把怪顶飞。
戴上按 R，换我亲自顶。

冲起来越跑越快，撞飞的普通怪，落地还得晕一会儿。
挡路的方块也能撞，但硬的得多顶一会儿。
左右键能慢慢拐弯，想主动刹车，记得再按 R。
头可以铁，刹车得记得。

（一秒插入：第三颗挂上）


# 烈焰人头

雷劈完了，再来点火。
烈焰人头扔出去，沿路铺下一道火径。
烧生物，不烧方块。

戴上免疫火焰，按住 R 就能喷火。
蓄满两秒再松手，还能甩出一道火浪；
遇上自己铺的火径，火浪就顺着往前烧。

不过，连续喷四秒就会过热停火。
火气再大，也得喘口气。

（一秒插入：第六颗挂上，天色已经明显偏晚）

# 铁傀儡头

前面都是小打小闹，来颗大的。
把铁傀儡头扔出去——
直接变成八倍大的铁头，下坡越滚越快，挡路的怪统统压扁。
落差够大，还能往地上砸个坑。
它在前面轰轰烈烈，我在后面毫发无伤。
不扔也有用，戴上加攻击、加护甲。

（一秒插入：第七颗挂上。镜头转回树边，树上七颗齐全，手里只剩猪头）

# 猪头

最后这颗猪头，戴着吃饭更顶饱。
那拿在手里，按左键呢？

我给它吞了。

饱食直接拉满，肚子也跟着鼓起来。
吃是吃饱了，走路都费劲了。

十秒一到，头吐回来，饱食也回到吞之前。
折腾半天，饱了个寂寞。

# 挂头收尾与闹鬼开场

（捡回猪头，走到树前）

行，最后这颗也挂上。

（完整挂头：第八颗就位。停一拍，只留挂头声）

八颗，齐了。

（镜头上摇，八颗头在枝上轻轻晃）

对了，这树有条规矩：
挂够八种头，半夜一到天亮之前，它自己会闹起来。

（缓推，天光往下掉，只留风穿过树枝的声音）

现在几点了？

（第一声铃响，画面转入夜里）

那就，看着吧。
