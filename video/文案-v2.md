# 开场

（盔甲架，八颗头一字排开，都只是静静地摆着）
MC里的头，光拿来摆着，多少有点浪费。
所以我做了个模组，添了几颗新头，并加了亿点功能。

# 僵尸头：获取与基本用法 ✅
先从已经有的僵尸开始
拿到僵尸头后，左键往外一扔
它就会自己蹦着找目标咬。
身子虽然丢了，但胃口没丢。

戴到头上，又是另一套技能。
以前回血靠干饭，现在口味倒着转：
一般食物吃了直接中毒，
只有吃腐肉才是补。
虽然不回血，但送力量和急迫效果

而且近战徒手打人还能吸血，
血量压得越低，输出反而越高
别人残血想着跑
我残血还想追着咬。
攻速和移速都会更快。
另外，由于攻击速度变快，徒手刨矿比镐子还管用。
（欧拉欧拉欧拉欧拉）

那么代价呢，代价就是我的攻击性会变得比较强
因为带上之后饱食度会立刻见底，普通食物没法吃
打人变成了我唯一回血的手段
所以现在见到谁都想上去给一拳

# 末影人头 ✅
僵尸头让我打架有帮手，
那么末影人头让我干活不用动手。

往地上一扔，就会连着啃相邻的同种方块。
相邻方块连啃十六块，啃完还有掉落物。
多搞几颗头一起扔，直接拉起全自动多线程流水线
它在前面疯狂出力，
我在后头只管捡漏。
突出一个惬意省心。

不过更重要的功能还是戴上以后
（i am bat man）
搞错了，带上之后，挨打瞬间会触发瞬移闪避。
每次闪避只需两秒的冷却，让我的身法宛如神助。

不过，落点好像是随机的。
(展示卡在墙里)
运气不好，会直接嵌进墙里
攻击是躲过去了，接下来该喊人救我出去了。

（第一次挂头）
对了，玩完的头如果暂时不用
可以放到盔甲架上，也可以统一挂到这棵树上。
收集党的老毛病了。

# 头获取方式
不过，头虽好用，获取起来实在不方便，还得请闪电苦力怕去炸。
所以为了稳定的获取头，
装备上这个拳套，对着生物哐哐三拳直接把头打掉
（展示打末影人、僵尸、苦力怕画面）
苦力怕直呼摸不着头脑，没了头也不会爆炸了

# 苦力怕头 ✅
那它的头又能干什么？当然是直接当手雷使。
扔出去3s准时爆炸
卡好时间，能捏个瞬爆直接带走
(引燃的时候闪白 + 音效)

周围生物听到这动静会叠加恐惧值
一级吓得拔腿就跑；
多听两秒就吓得原地发抖走都走不了；
3级恐惧还有额外的收获
羊直接下的毛掉一地，省去了我们剪羊毛的时间

村民会连忙交出手里的钱。
不用动手，直接把保护费都收齐了。
（展示恐惧一键收羊毛，村民集中营收钱）

有了这个我可以横着走，谁见我都要包头鼠窜

(点燃引线，追着苦力怕跑)
这不是苦力怕吗，你能给我交点什么？
以前都是我害怕，今天换你来体验一把。


跑啊，你怎么不跑了？
……不是，你怎么开始亮了？
我是让你爆点装备，咋还和我拼命呢？


戴上就更有意思了。
按 R 放一发弹药，再按 R 遥控引爆。
可以当遥控炸弹使用
另外这次爆炸对本人不造成伤害，还可以作为强力赶路工具把自己炸飞
(插入瑞兹的一些语言或者梗)


# 青蛙头 ✅
（戴上青蛙头）
戴上青蛙头以后，
我发现人也不一定非得长手。
十六格以内，全凭舌头。

（隔空拉回地上的掉落物）
捡东西？动动嘴就行。
需要挖方块？动动嘴就行
不过术业有专攻，不要指望一个舌头能把钻石矿舔下来，不然稿子都可以下岗了

（隔空拆掉箱子，箱子和里面的物品全被卷走）
开箱也是一口的事，连箱子都能一起带走。
主打一个吃干抹净、滴水不漏。
就这隔空打包的手艺，隔壁搜打撤玩家看到都馋哭了

不光能隔空捡物，
飞来的攻击也能一口接住。
骷髅的箭，恶魂的火球，都是可以吞的
虽然含着火球多少有点烫嘴，
但反手一口原路吐回——
还能解锁成就【空口接白刃】
（画面：火球以 1.5 倍超高速原路呼啸射出，轰然把恶魂当场凌空炸碎！屏幕跳出成就【空口接白刃】）

当然，光吃投掷物，格局还是小了。
以后打怪直接一口闷
不管你是僵尸、骷髅、大的、小的、高的、矮的，在我这都是一口的事情
嚼几口直接消化，经验和掉落也不会落下

有人整活嘴咬打火机，我这直接来个口吞苦力怕。
（一口吞下，原声急促引线声响起）
等下，这声音不对
(原地爆炸)
太贪吃可不行，如果吃到脏东西还是赶紧吐掉，避免被直接送走；


# 烈焰人头 ✅
接着是烈焰人头
扔出去之后，会沿路铺下一道火径。

戴上免疫火焰，按住 R 就能喷火。
蓄满两秒再松手，还能甩出一道火浪；
如果遇上自己铺的火径，火浪还能顺着往前烧。

今天我就化身烹饪大师，给大家露一手。
先小火慢炖，再大火收汁
(先铺火路径，然后一口喷)
这效率，熔炉看了都得抖一抖。

如果一直按住 R 不撒手，可以蓄力发射一发火球
不过这大招威力虽然强，但后劲也不小。
一发轰出去，会直接熄火8秒；


# 兔子头 ✅
还有些头看着朴素，功能却相当实用。
比如这颗兔子头——
戴上以后，只要在落地瞬间接着跳，就能越跳越高
连续跳到第十六下
直接带你体验，什么叫扶摇直上九万里！
而且落地是不会受到伤害的。

# 山羊头 ✅
然后试试这颗山羊头。
带上之后，解锁无畏冲锋
别管眼前有什么，先顶飞再说
（直接顶飞撞到的生物）
脆皮障碍全速撞穿，遇到硬石头就硬顶强拆
只要不是基岩，在我面前顶多算个减速带！

不过……这招有个致命弱点，就是没有刹车
油门彻底焊死，角度只能微调。 
撞不到目标是常有的事情，一不留神，还可能解锁岩浆游泳
所以我增加了一个功能
按住潜行键可以解锁漂移过弯
（开始逮虾户）


# 猪头 ✅
最后这颗猪头，戴着吃饭更顶饱。
当然也可以直接一口吞了
直接变成大胃袋
饱食度拉满，吃是吃饱了，就是走路有点费劲。
不过一口吃这多肯定消化不了的，
过一会儿会吐掉的
不然我的世界就成我的大胃袋了
