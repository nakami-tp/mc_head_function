# 开场

（盔甲架，八颗头一字排开，都只是静静地摆着）
MC里的头，光拿来摆着，多少有点浪费。
所以我做了个模组，添了几颗新头，并加了亿点功能。

# 僵尸头：获取与基本用法
先从已经有的僵尸开始
拿到僵尸头后，左键往外一扔
它就会自己蹦着找目标咬。
身子虽然丢了，但胃口没丢。

戴到头上，又是另一套技能。
以前回血靠干饭，现在口味倒着转：
吃别的都是毒，吃腐肉才是补
不仅回血还送力量和急迫效果

而且近战打人还能吸血，
别人打架掉血，我打架回血。
血量越低，伤害越高
攻速和移速都会更快。
别人残血想着跑，我残血还想追着咬。
另外，由于攻击速度变快，徒手挖矿也不再麻烦
（欧拉欧拉欧拉欧拉）

那么代价呢，代价就是我的攻击性会变得比较强
因为带上之后饱食度没法补偿，砍人变成了我唯一回血的手段
现在见到谁都想上去砍一刀

# 末影人头
僵尸头让我打架有帮手，
那么末影人头让我干活不用动手。

往地上一扔，就会连着啃相邻的同种方块。
一次最多十六块，啃完还有掉落物。
头负责干活，我负责捡。
多收集几个头，一起扔出去，挖矿、砍树，多线程并行，非常的省心。

戴上以后，挨打瞬间会触发瞬移闪避。
可以躲掉一次伤害，每次只要两秒冷却，保命能力直接起飞。

不过，落点好像是随机的。
(展示卡在墙里)
运气不好，会变成这样。
攻击是躲过去了，接下来该喊人救我出去了。

（第一次挂头）
玩完的头如果暂时不用，可以放到盔甲架上，也可以统一挂到这棵树上。
收集党的老毛病了。

# 头获取方式
不过，头虽好用，获取起来实在不方便，还得请闪电苦力怕去炸。
所以为了稳定的获取头，
装备上这个拳套，对着生物哐哐三拳直接把头打掉
（展示打末影人、僵尸、苦力怕画面）
苦力怕直呼摸不着头脑，没了头也不会爆炸了

# 苦力怕头
那它的头又能干什么？当然是直接当手雷使。
扔出去3s后爆炸
也能拿在手上温一温，捏个瞬爆。
(引燃的时候闪白 + 音效)

周围生物听到这动静会叠加恐惧值
1级落荒而逃
2级发抖减速
3级还有意外收获
鸡下蛋，羊掉毛，村民连忙交出手里的钱。
不动手，直接把保护费都收齐了。

那苦力怕，你能给我交点什么？
(点燃引线，追着苦力怕跑)
以前都是我害怕，今天换你体验一把。
我这心理阴影有多大，你现在知道了吧？

跑啊，你怎么不跑了？
……不是，你怎么开始亮了？
我是让你爆点装备，咋还和我拼命呢？


戴上就更有意思了。
按 R 放一发弹药，再按 R 遥控引爆。
可以当遥控炸弹使用
另外这次爆炸对本人不造成伤害，还可以作为强力赶路工具把自己炸飞
(插入瑞兹的一些语言或者梗)


# 青蛙头
（戴上青蛙头）
戴上青蛙头以后，
我发现人也不一定非得长手。
十六格以内，全凭舌头。

（隔空拉回地上的掉落物）
捡东西？动动嘴就行。
需要挖方块？动动嘴就行
不过术业有专攻，不要指望一个舌头能把钻石矿舔下来，不然稿子都可以下岗了

（隔空拆掉箱子，箱子和里面的物品全被卷走）
开箱也是一口的事，连箱子带包装一起带走。
顺手解锁【隔空开箱】，主打一个吃干抹净。
这能力，隔壁搜打撤都馋哭了

不光可以捡东西，还可以接投掷物
骷髅的箭，恶魂的火球，都是可以吞的
虽然有点烫嘴，不过可以原样吐出去
（画面：火球以 1.5 倍超高速原路呼啸射出，轰然把恶魂当场凌空炸碎！屏幕跳出成就【空口接白刃】）

当然，只是吃一下投掷物，那个格局还是太小了
以后打怪直接一口闷，不管你是僵尸、骷髅、大的、小的，在我这都是一口的事情
嚼几口直接消化，经验和掉落也不会落下

有人整活嘴咬打火机，我这直接来个口吞苦力怕。
（一口吞下，原声急促引线声响起）
等下，这声音不对
(原地爆炸)

为了防止吃到脏东西，留了可以吐出来的选择
避免吃到脏东西被直接送走；

还有这颗兔子头。
戴上以后，落地瞬间接着跳，就能越跳越高


跳到第十六下，可以直接体验什么叫 扶摇直上九万里
不过放心，这一跳落地不会摔伤。

不想跳那么高，按 R 就能重置。
行，蹦跶完了，看看下一颗。

# 山羊头
接着试试这颗山羊头。
扔出去，能把怪顶飞。
戴上按 R，换我亲自顶。

冲起来越跑越快，撞飞的普通怪，落地还得晕一会儿。
挡路的方块也能撞，但硬的得多顶一会儿。
左右键能慢慢拐弯，想主动刹车，记得再按 R。
头可以铁，刹车得记得。

（一秒插入：第三颗挂上）


# 烈焰人头

雷劈完了，再来点火。
烈焰人头扔出去，沿路铺下一道火径。
烧生物，不烧方块。

戴上免疫火焰，按住 R 就能喷火。
蓄满两秒再松手，还能甩出一道火浪；
遇上自己铺的火径，火浪就顺着往前烧。

今天我就化身烹饪大师，给大家露一手。
先小火慢炖，再大火收汁
(先铺火路径，然后一口喷)
这效率，熔炉看了都得抖一抖。

不过，火气再大，也得喘口气。
连续喷四秒就会过热停火。


# 铁傀儡头
怎么能少了我们铁哥
把铁傀儡头扔出去——
直接变成八倍大的铁头，下坡越滚越快，挡路的怪统统压扁。
落差够大，还能往地上砸个坑。
它在前面轰轰烈烈，我在后面毫发无伤。
不扔也有用，戴上加攻击、加护甲。

（一秒插入：第七颗挂上。镜头转回树边，树上七颗齐全，手里只剩猪头）

最后这颗猪头，戴着吃饭更顶饱。
当然也可以直接一口吞了
直接变成大胃袋
饱食度拉满，吃是吃饱了，就是走路有点费劲。
不过一口吃这多肯定消化不了的，
过一会儿会吐掉的
不然我的世界就成我的大胃袋了
