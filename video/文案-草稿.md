# 开头钩子

（铁傀儡头压路机效果快切，完整展示留到后面）

你见过拿铁傀儡的头，当压路机的吗？

# 介绍

（盔甲架＋八种头展示）
MC 里的头，光拿来摆着，多少有点浪费。
所以我做了个模组，添了几颗新头，也给原有的头加了点本事。
今天先挑八颗，看看它们有多能整活。

# 僵尸头：获取与基本用法

这些头怎么拿？先找只成年僵尸。
空手瞄准头，两秒内敲三下。
不掉血，只掉头。
身子还在原地乱走——它是真没头绪了。

模组支持的其他成年生物，也能这么取头。
拿到僵尸头，左键扔出去，它就会自己蹦着找目标咬。
身子丢了，胃口没丢。

那右键戴上呢？连食谱都变了：
吃面包中毒，吃腐肉回血，还送力量和急迫。
近战打人也能吸血。
别人打架费血，我打架回点血。

# 末影人头

打架有帮手，挖矿也能偷个懒。
末影人头往矿上一扔，就会连着啃相邻的同种方块。
一次最多十六块，啃完还有掉落物。
头负责挖矿，我负责捡。
这分工，听着就省心。

戴上以后，挨打时还会尝试瞬移闪避。
瞬移成功，这一下才不掉血；
没找到落脚点，该挨的打还是得挨。
而且成功一次，还得等五秒冷却。

# 挂头树伏笔

（展示枯树的挂头用途，暂不揭示闹鬼）

矿得收，头也得收。
我还准备了一棵专门挂头的枯树。
收集到的头往上一挂，收藏党应该挺喜欢。
先放这儿，待会儿再挂。

# 山羊头

收集归收集，接着试试这颗山羊头。
扔出去，能把怪顶飞。
戴上按 R，换我亲自顶。

冲起来越跑越快，撞飞的普通怪，落地还得晕一会儿。
挡路的方块也能撞，但硬的得多顶一会儿。
左右键能慢慢拐弯，想主动刹车，记得再按 R。
头可以铁，刹车得记得。

# 苦力怕头

撞过去还不够过瘾？再试试炸过去。
苦力怕头扔出去，碰哪炸哪，直接当手雷使。

戴上就更有意思了。
按 R 放一发弹药，再按 R 遥控引爆。
放怪旁边，炸怪；放自己脚边，把自己送上天。
这次爆炸不伤自己，炸飞后落地也不掉血。
炸别人是武器，炸自己是交通。

# 闪电苦力怕头

换成闪电苦力怕头，扔出去还能穿墙开路，大约八格后爆开。
戴上后，对准十六格内、没被方块挡住的怪，按 R 就能劈雷。
平时五秒充好，雷雨天只要两秒半。
天气越差，我发挥越好。

# 烈焰人头

雷劈完了，再来点火。
烈焰人头扔出去，沿路铺下一道火径。
烧生物，不烧方块。

戴上免疫火焰，按住 R 就能喷火。
蓄满两秒再松手，还能甩出一道火浪；
遇上自己铺的火径，火浪就顺着往前烧。

不过，连续喷四秒就会过热停火。
火气再大，也得喘口气。

# 铁傀儡头：兑现开场

接下来，轮到开头那台压路机了。
把铁傀儡头扔出去——
直接变成八倍大的铁头，下坡越滚越快，挡路的怪统统压扁。
落差够大，还能往地上砸个坑。
它在前面轰轰烈烈，我在后面毫发无伤。
不扔也有用，戴上加攻击、加护甲。

# 猪头

最后这颗猪头，戴着吃饭更顶饱。
那拿在手里，按左键呢？

我给它吞了。

饱食直接拉满，肚子也跟着鼓起来。
吃是吃饱了，走路都费劲了。

十秒一到，头吐回来，饱食也回到吞之前。
折腾半天，饱了个寂寞。

# 挂头收尾与闹鬼反转

（捡回猪头，挂上枯树）

行，最后这颗也挂到树上。
这下，齐活了。
