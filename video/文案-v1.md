# 开头钩子
(铁傀儡头功能展示)
你见过拿铁傀儡的头，当压路机的吗？

# 介绍
(盔甲架 + 8种头展示)
MC的头部物品只有装饰作用，所以为了让头部装备更有用，我增加了一些新的头部物品，并扩展了原有头部的功能
今天就挑这八颗展示下


# 头部装备获取方式
先说下头部装备怎么获取
空手瞄准头，两秒内敲三下。
不掉血，只掉头。
身子还在原地乱走——它是真没头绪了。


# 僵尸头
头有两种用法，可以直接扔出去，也可以装备上
先来看看僵尸头
扔出去后，会自己蹦着找目标咬。
身子丢了，胃口没丢。
戴上以后，吃面包中毒，吃腐肉回血，还加力量和急迫。
且近战攻击还能吸血。


# 末影人
末影人头扔到矿上，会连着啃相邻的同种方块。
最多十六块，啃完留下掉落物；
这样提高了平时的工作效率
头负责挖矿，我负责捡。
如果装备上就是一个很好的防具，挨打后会瞬移闪避。
成功才免伤，不过并不是无敌了，还有五秒冷却的

(伏笔)
**另外我还准备了一颗树可以把收集到的头挂在树上，很适合喜欢收集的玩家**

# 苦力怕
苦力怕头，当然是扔出去碰哪炸哪。可以当做手雷
重点还是戴着的时候，按 R 放弹药，再按引爆，能把自己炸飞，也可以作为遥控炸弹炸其他生物。
这次爆炸不伤自己，落地也不摔血。
炸别人是武器，炸自己是交通。

# 闪电苦力怕
换成闪电苦力怕，扔出去一路穿墙，八格后再爆开。
戴上对准十六格内的怪，按 R 就能劈雷。
平时五秒充好，雷雨天只要两秒半。
天气越差，我发挥越好。

# 烈焰人
烈焰人头扔出去，沿路铺火径，烧生物，不烧方块。
戴上免疫火焰，按住 R 喷火，蓄两秒松手，再甩一道火浪。
碰上自己留下的火径，还会顺着烧过去。
但连喷四秒就过热。
火气再大，也得喘口气。

# 山羊头
山羊头扔出去顶飞怪，戴上按 R，换我亲自顶。
冲起来可以撞飞怪，落地还会增加眩晕。
如果撞到方块可以把方块顶碎
记住，再按 R 才能主动刹车。

# 铁傀儡
嫌自己冲还不够狠？把开头那颗铁傀儡头扔出去。
直接变成八倍大的铁头，下坡越滚越快，挡路的怪都给压扁。
落差够大，还能砸个坑。
至于扔它的我，毫发无伤。
戴上也能加攻击、加护甲。

# 猪头
最后这颗猪头，戴着吃饭更顶饱。
左键呢？
我把它吃了。
肚子是大了，走路都费劲了。
十秒后，头吐回来，饱食也回到原样。
折腾半天，饱了个寂寞。
