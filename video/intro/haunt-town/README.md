# 万圣节小镇改造

2026-10-11：将四栋平顶测试木屋替换为约 64×64 的万圣节街区，中心继续使用原有闹鬼枯树。

- 六栋可进入的建筑：弯月酒馆、南瓜面包铺、夜灯草药屋、丰收小屋、乌鸦裁缝铺、铜铃工坊。按用途配置柜台、床、桌椅、灶台、工具和陈列。
- 半木结构外墙、不同材质的坡屋顶、突出屋檐、窗台花盆、门廊和冒烟烟囱；酒馆带楼梯与二层客房。
- 连通道路与枯树广场、条纹雨棚集市、麦田南瓜菜圃、货运轨道、长椅、树篱与秋色树。
- 南瓜灯、橙紫节庆悬饰、暖色灯笼和穿南瓜头的盔甲架提供节庆气氛。九类宿主都多于默认附身数量。

## 使用

加载新构建后执行 `/haunt town reset` 重建已记录的小镇，或在新位置执行 `/haunt town build`。仍会覆盖生成范围里的方块和非玩家实体；手动改动不会保存。

真实客户端验收：`./gradlew runHauntValidation`。它创建独立平坦测试世界，固定镜头，验证入口与室内通行、宿主数量、实际附身后的重建，并保存白天、傍晚、室内截图；完成后自动关闭。

原始结果在 `build/haunt-validation/`；本目录保留改造前与验收后的实机画面。`before.png` 是本次修改前、同一总览镜头截图。

## 外景与居民扩展

在原有街区外四周各扩约 24 格，总生成/重建范围为 **112×112**。新建南侧镇门与进镇路、西侧池塘和木桥、秋林低丘、果园、南瓜麦田、小墓园、牛羊圈和鸡舍。

每次固定生成 **6 名村民、3 头牛、4 只羊、5 只鸡、2 只猫**。出生位置固定，保留正常 AI 与伤害，不会自然消失。重建恢复人口；通过持久化批次标记，在重新加载区块时清除重建前保存的旧居民，避免重复。
