# 功能优化

# 苦力怕头

戴在头上的时候，r键扔出后，再次r不是扔第二发，而是直接引爆第一发，也就是说不能同时扔2发出去再引爆

## 手持温雷与恐惧升级（待实现）

目标：先通过普通生物的逃跑、发抖减速和三级掉落物品，让玩家以为恐惧越高越安全、收获越多；最后用苦力怕三级恐惧时的应激自爆完成反转。本节为新增需求，尚未实现。

### 手持投掷与温雷

- 普通手持苦力怕头使用左键，不需要佩戴，也不使用 R；头戴能力保持现状。
- 普通投掷改为出手后约 3 秒爆炸，替代当前碰撞即爆的行为。
- 长按左键可在手上温雷，从点燃起计时约 3 秒；松开左键投掷，剩余引信时间延续，不因出手重置，可通过温雷捏出瞬爆。
- 温雷期间有点燃、闪白和引信音效；临近爆炸时闪白和音效加快。温雷超时按引信正常爆炸，但不把故意炸手作为演示的反转。
- 保留普通投掷爆炸的方块破坏和头部回收规则；不要将其与头戴 R 技能的弹药、遥控引爆、自身免伤和落地保护混为一套。

### 三级恐惧

周围生物持续受到手持温雷的声响刺激时积累恐惧；离开刺激范围后逐渐消退。恐惧允许跨多次温雷累积，不要求在单次三秒引信内完成全部升级。普通投掷物是否继续施加恐惧、作用距离、各级阈值和消退速度待实机调试。

| 等级 | 基础行为 | 表现目的 |
| --- | --- | --- |
| 一级：惊慌 | 停止攻击，落荒而逃 | 让玩家可以追着生物吓唬 |
| 二级：胆寒 | 明显发抖并减速 | 强化“越害怕越跑不动”的印象 |
| 三级：崩溃 | 指定生物开始掉落可拾取物品；苦力怕触发应激自爆 | 先让玩家获得收益，再用苦力怕反转 |

- 覆盖动物、村民与普通敌对生物；玩家、Boss 等特殊对象的适用规则待实现前明确。
- 二级减速的强度、持续时间，以及三级掉落数量、重置与冷却待调试。取消此前的二级虚弱与三级通用惊吓掉血设计。
- 普通生物的恐惧行为与三级特殊反应均不得主动危害玩家，苦力怕三级除外。

### 三级特殊反应

- **鸡**：吓到下蛋。
- **羊**：吓掉羊毛，进入剪毛后的外观；不能重复产出同一身羊毛。
- **村民**：吓到掉落绿宝石，生成可拾取的物品实体。
- 以上特殊反应每次完整的恐惧过程最多触发一次，不能在二、三级之间反复切换来刷掉落；具体重置与冷却待调试。
- **苦力怕**：前两级与普通生物一致；三级不触发恐惧物品掉落，而是应激自爆。先停止逃跑、短暂停顿，再转身点燃并主动逼近恐惧来源玩家。点燃后不再被温雷恐吓打断，避免刚反扑又被吓跑。
- 苦力怕三级应激自爆属于生物自身爆炸，正常伤害玩家，不适用玩家头戴弹药的自身免伤；普通与带电苦力怕的差异沿用其自身爆炸规则。
- 停顿与引爆节奏需留出“跑啊，你怎么不跑了？……不是，你怎么开始亮了？”的反应窗口，不能升到三级就无预兆瞬爆。

### 实现后重点验证

- 左键点按投掷、长按温雷及松手投掷不重复触发；投出后不重置引信，碰撞不提前引爆，爆炸后仍可回收头。
- 恐惧能正常升级、消退，且实际温雷节奏能达到三级；二级正确发抖减速，退出恐惧后清理逃跑、发抖和减速效果，不施加旧设计中的虚弱或惊吓伤害。
- 鸡蛋、羊毛和绿宝石可正常拾取，不会因重复升级、重复事件或多人同时恐吓而重复生成。
- 苦力怕有可观察的停顿、转身和点燃过程，能反扑伤害玩家；骷髅不再配置三级丢弓反应。
- 现有头戴 R 投放、再按 R 引爆、充能、自身免伤和当次落地保护不受影响。
