# 僵尸徒手按住连打与真实挖掘加速

2026-10-26；当前规则见 `.scratch/zombie-wear/spec.md`。

## 改动

- 在原版持续挖掘输入处理结束处，仅对僵尸模式徒手、准星命中活实体、攻击冷却已完全恢复时补一次原版攻击；每 tick 最多一次，首次单击不会叠加重复攻击。
- 松手、界面、失焦、使用物品、眩晕、持物、摘头均不满足连打条件。方块目标继续走原版持续挖掘。
- 客户端和服务端的 `PlayerEntity.getBlockBreakingSpeed` 均使用僵尸徒手攻速倍率 `1 + 4 × 缺失生命比例`；原版急迫、硬度、工具适用性、掉落要求与环境惩罚仍参与计算。

## 验证命令

```sh
./gradlew -I scripts/testing/zombie-isolated.gradle test runGameTest build
./gradlew -I scripts/testing/zombie-isolated.gradle runZombieValidation
```

47 项 JUnit 测试、41 项相关 GameTest 通过，构建成功。新增服务端 GameTest 覆盖半血 3 倍、濒死接近 5 倍的空手挖掘速度和实际方块破坏进度；持工具/摘头无加成，需要工具才能采收的石头仍不能空手采收。

真实客户端在原有僵尸战斗、吸血、饮食、疾跑回归之后，新增场景通过真实按键按住状态与一次按下事件操作原版输入，不直接循环调用攻击或破坏方块方法：

- 按住对准生物可连续发送攻击，服务端记录多次攻击尝试；实际伤害继续遵循原版受伤无敌帧等规则。
- 松手停止；打开背包后即使攻击键状态维持按下也停止；持剑时只有最初一次原版点击。
- 普通空手与残血僵尸空手挖同种木板，实测分别 61 tick、20 tick；两次破坏均由服务端确认。测量包含原版启动/连续破坏间隔与整数 tick，不将速度倍率直接等同为完整破坏耗时倒数。
- 最少粒子设置；已查看 `05-held-fist-combat.png` 与 `06-fast-hand-mining.png`。前者显示攻击与回血反馈，后者为破坏末帧与掉落物；完成判定以客户端方块状态和服务端方块状态断言为准。

最新结果在 `build/zombie-client-validation/result.txt`；截图在对应目录的 `screenshots/`。发布 JAR 不含测试或客户端验证类。失焦、使用物品和眩晕分支由条件检查确认，本次未分别自动操作这些场景。
