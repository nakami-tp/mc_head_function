# 僵尸残血吸血与拳套专属摘头调整

2026-10-26，在僵尸佩戴首版基础上调整。

## 行为

- 普通徒手吸血率 `0.20 + 0.60 × 缺失生命比例`，精通 `0.30 + 0.70 × 缺失生命比例`。按命中前生命比例和目标实际扣除生命计算，击杀额外回复 6 点保留。
- 例如满血理论率 20%/30%，半血 50%/65%，剩余 10% 生命时 74%/93%；实际回复仍受生命上限限制，满血不出现回流。
- 空手打头走普通伤害，不撼头、不累计摘头次数；仅主手断头拳套可斩首，拳套仍为约两秒内三拳、无伤害。

## 验证

```sh
./gradlew -I scripts/testing/zombie-isolated.gradle test runGameTest build
./gradlew -I scripts/testing/zombie-isolated.gradle runZombieValidation
```

- 47 项 JUnit 测试、40 项 GameTest 通过。本轮隔离注册僵尸、原头功能和拳套摘头测试。
- 新增相同实际伤害、不同当前生命的普通/精通吸血回归；实际头部准星命中三次造成伤害和回血、不掉头、不摇头的回归。
- 保留吸收生命、玩家目标、满血回复封顶、持物停用、击杀额外回复以及拳套三拳断头的回归。
- 真实客户端在最少粒子设置下通过：低血强化吸血同步到客户端，三次正常攻击包命中目标头部仍保留头部，满血不出现回血回流，空饱食疾跑和持物停用仍通过。
- 已有摘头客户端场景的初始斩首改为使用拳套，避免旧夹具继续依赖空手摘头；本轮没有重跑整套拳套动画场景，拳套服务端行为由 GameTest 覆盖。
- 测试玩家在各自测试场景内初始化，避免随机世界出生点干扰手动推进的玩家 tick。
