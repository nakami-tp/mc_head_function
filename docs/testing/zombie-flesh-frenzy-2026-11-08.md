# 僵尸头腐肉狂暴验收（2026-11-08）

腐肉力量 I、急迫 I 从 10 秒变为 50 秒。同期佩戴僵尸头的生存/冒险玩家免伤，不吸血、不获击杀回血；残血徒手连打可以突破目标原版受伤间隔，并以很低的弹跳一路向前颠飞。保留用户明确要求的大额伤害心形粒子。

## 可重复命令

```sh
./gradlew -I scripts/testing/zombie-isolated.gradle test runGametest build
MC_HEAD_ZOMBIE_FRENZY_ONLY=true ./gradlew -I scripts/testing/zombie-isolated.gradle runZombieValidation
./gradlew -I scripts/testing/zombie-isolated.gradle runZombieValidation
```

狂暴场景输出到 `build/zombie-frenzy-validation/`，原有场景输出到 `build/zombie-client-validation/`。两者都创建独立世界并自动退出，不接触用户存档。发布包为 `build/zombie-isolated/libs/mc-head-function-1.0.0.jar`，不含测试入口。

## 结果

- 56 个 JUnit 用例通过；46 个相关 GameTest 通过；构建通过。
- 原有完整客户端验收通过：空饱食疾跑、普通吸血/击杀回流、按住攻击与界面/持物停止、空手拾取、真实挖掘、左右手/盾牌/第一及第三人称姿态均回归。首次旧场景因窗口失焦停止自动连打而失败；测试按键入口补足聚焦后复验通过，正式玩法的失焦停攻规则保持原样。
- GameTest 经真实吃腐肉入口断言力量/急迫均为 1000 tick，狂暴在第 999 tick 仍免伤、第 1000 tick 到期。覆盖普通伤害、饥饿、摔落、岩浆及虚空伤害；牛奶、摘头和重新佩戴边界；普通力量/急迫不触发。
- 真实徒手连打验证每次伤害、向前速度、低弹跳、命中与击杀都不回血；武器和其他玩家保留原版目标受伤间隔，拒绝命中不会清掉原有间隔。
- 实机以 Hard 难度、最少粒子、半颗心、零饱食开场，实际使用键吃掉最后一块腐肉，按住攻击并通过移动键追击尸壳。测试目标关闭自主移速、保留物理与 AI，并增加生命/抗性以撑过连击。
- 最终场景经过 79 个服务端 tick，收到 67 次真实扣血，其中 66 次与上次间隔不超过 3 tick；目标前进 18.381 格，最高离地 0.570 格。玩家始终 1 点生命，期间反复尝试的伤害全部被阻止；真实击中反馈可见，无吸血回流。
- 客户端确认狂暴状态已同步、背包图标能解析；图标通过图集别名沿用原版力量图案。已查看第一及第三人称关键帧，确认大量心形伤害粒子保留、目标低空向前移动、玩家保持半颗心。
- 80 张实际采样截图在 `build/zombie-frenzy-validation/screenshots/`；`zombie-juggle.mp4` 为这些帧按 20 fps 编码的 4 秒无声预览，不代表真实墙钟录屏或音频采样。
