# 头部功能

Status: ready-for-agent

词表见 [CONTEXT.md](../CONTEXT.md)。难回头的物品决定见 [ADR 0001](adr/0001-reuse-vanilla-heads.md)。需求原文见 [需求.md](需求.md)。第一期数字与逐颗例外见 [HANDOFF.md](../HANDOFF.md)。

## Problem Statement

原版头盔颅只有装饰。玩家不能从活着的表内生物上取头，也不能把拿到的头扔出去做效果，或戴着发动头技。头用一次就没了的话，也不值得收集。

## Solution

给表内生物的头加上斩首、投掷、佩戴和头技。斩首后身体还活着、只剩无目标乱走。头可以反复投掷，效果结束后回收成地上物品。原版已有的僵尸头、苦力怕头就是那一颗；原版没有的表内头由本模组新增。

## User Stories

1. As a 生存玩家, I want 原版头颅不再只是装饰, so that 收集头有玩法理由
2. As a 生存玩家, I want 空手对表内生物头部撼头三次来斩首, so that 我能在不击杀的情况下拿到头
3. As a 生存玩家, I want 撼头不造成近战伤害, so that 我不会把目标误杀掉
4. As a 生存玩家, I want 只斩碰撞箱上 1/3, so that 打身体仍是普通攻击
5. As a 生存玩家, I want 同一目标约 2 秒内三下才算斩首, so that 误点一下不会把头打飞
6. As a 生存玩家, I want 斩首时有打击反馈, so that 我知道撼头算数
7. As a 生存玩家, I want 幼体不能被斩首, so that 小僵尸不会掉成体头
8. As a 生存玩家, I want 玩家、Boss、表外生物不能被斩首, so that 范围清楚
9. As a 生存玩家, I want 斩首后头沿视线打飞两三格再变成物品, so that 头是「打下来」而不是凭空出现在脚边

## Implementation Decisions

- 在 Fabric 1.21.1、Yarn、Fabric API 上实现；包名保持现有模组入口。
- 头的身份按表内种类区分。原版僵尸头、苦力怕头复用原版物品并挂上能力；其余表内头新注册为可戴头盔槽的物品。见 ADR 0001。
- 斩首只认表内成体。带电苦力怕与普通苦力怕是同一实体类型上的两种头。尸壳、溺尸、流浪商人羊驼等表外变种不斩。
- Boss 按末影龙、凋灵、监守者处理。
- 斩首命中用准星与碰撞箱的交点是否落在上 1/3 判定；窗口是从第一下起约 2 秒内凑满三下。
- 打飞和投掷共用「会飞的头」实体，用样式区分：打飞是短距视线飞行后回收；投掷按种类走飞行中，必要时进生效中，再回收。
- 飞行中 / 生效中 / 回收是同一颗头的三态。默认投掷、山羊顶、苦力怕手持小爆、闪电苦力怕穿爆、烈焰人火线等没有或只有极短的生效中；僵尸跳咬、末影吃块、铁傀儡滚动有生效中。
- 回收生成地上物品。虚空与岩浆销毁实体且不掉物品。爆炸伤害对飞行中 / 生效中的头无效。
- 无头是原实体上的持久标记：关 `setTarget`、隐藏头模型、死亡掉落过滤第二颗头。不生成新实体。
- 投掷由客户端左键发起、服务端生成投射物并消耗主手（创造不消耗）。持头时取消方块破坏。
- 伤害对象：所有活物，排除投掷者。铁傀儡冲击波不例外。
- 召唤物（蜜蜂）打上「属于谁」的标记。回收和 10 秒时限不管它们。佩戴蜜蜂头只导航 / 护主已有标记蜂。
- 弹药是独立投射物，不是头。苦力怕头技：有充能就扔，充能耗尽或场上已有 2 发则引爆已有弹药。引爆后消失。
- 头技只走独立按键，默认 R，可改。点按、再按、按住都走这颗键。服务端按「按下 / 松开」处理喷火。
- 抓取：准星射线第一击中；16 格；1 秒冷却；方块和容器按空手掉落并进背包。
- 蝙蝠声呐：头立刻回收；透视作为只对投掷者可见的客户端效果挂约 5 秒。
- 第一期数值按交接建议表落地，手感以后再调。抓取改成 16 格只改抓取；末影闪避、弹药击退、铁傀儡滚动仍约 8 格。
- 新注册头第一期用可装备物品，不新做原版头颅方块那套 3D 头模型。

## Testing Decisions

好测试只断言玩家能观察到的结果：会不会斩首、会不会受伤、头最终是物品还是没了、戴着时按 R 发生什么。不断言 mixin 注入点、数据包字段名或内部计时器怎么加。

**主 seam（已确认）：玩家面向的头部规则。**  
给定玩家动作（空手撼头 / 左键投掷 / 佩戴 tick / 头技按下或按住）和世界里的目标，观察：目标是否变成无头身体、是否出现飞行中或生效中的头、是否回收、谁掉血、是否出现召唤物或弹药。整张表都走这一条 seam，不按头再拆测试入口。

已有的低层 seam 只覆盖不依赖世界的规则：三下时间窗、碰撞箱上 1/3、末影禁吃、雷雨充能减半、投掷者不挨打。它们服务主 seam，不是第二套产品入口。

不在 mixin、渲染器、键位注册上单测。进游戏手感（粒子、模型隐藏、声呐线框）用手测，不写入自动测试契约。

## Out of Scope

- 给骷髅头、凋灵骷髅头、猪灵头、龙首等表外头加能力
- 把头安回无头身体
- 第二套「功能头」物品与原版头并行
- 召唤物跨存档永久
- 幼体、玩家、Boss 斩首
- 第一期之后的数值调参当作本 spec 的验收
- 新头的原版级 3D 头颅模型与地牢战利品表扩展（除「原版僵尸/苦力怕头已有能力」外）
